Servicios externos

La web se aloja en GitHub Pages, que puede registrar direcciones IP por motivos de seguridad. Estos proveedores pueden tratar datos fuera del Espacio Económico Europeo; consulta sus políticas para conocer sus condiciones y garantías: GitHub y Google. Los enlaces a redes sociales están sujetos a las políticas de sus respectivos servicios.
